  3. Membangun formulir interaktif yang memenuhi standar aksesibilitas WCAG 2.2.
  4. Menerapkan prinsip estetika CSS modern (aturan 60-30-10, soft shadow, & border radius).
  5. Melakukan versioning terstruktur menggunakan Git dan deployment live di GitHub Pages.
